# Recording a Demonstration Video for SDR Triangulation Application

This guide provides instructions for recording a demonstration video of the SDR Triangulation Application in action. The demonstration video will showcase the key features and functionality of the application.

## Preparation

1. Ensure the SDR Triangulation Application is fully set up and running
2. Connect to at least two KiwiSDR receivers for triangulation demonstration
3. Prepare a list of features to demonstrate
4. (Optional) Create a script to follow during the recording

## Recommended Recording Tools

### Windows
- **Windows Game Bar** - Built-in screen recorder
  - Press `Win + G` to open
  - Click the "Record" button to start recording
- **OBS Studio** - Free, open-source recording software
  - Download from [obsproject.com](https://obsproject.com/)
  - Set up a "Display Capture" source
  - Configure recording settings (format, quality, etc.)
  - Use the "Start Recording" button

### macOS
- **QuickTime Player** - Built-in screen recorder
  - Open QuickTime Player
  - Go to File > New Screen Recording
  - Select the recording area and start recording

### Linux
- **OBS Studio** - Available for Linux
- **SimpleScreenRecorder** - Lightweight alternative

## Features to Demonstrate

1. **Application Startup**
   - Show the process of starting the application
   - Explain the configuration options briefly

2. **Connecting to KiwiSDR Receivers**
   - Show the process of connecting to multiple KiwiSDR receivers
   - Demonstrate the receiver status indicators

3. **Signal Detection**
   - Tune to a frequency with active signals
   - Show the waterfall display and explain the signal detection process
   - Demonstrate adjusting parameters for signal detection

4. **Triangulation Process**
   - Show how the application calculates signal origin
   - Demonstrate the map visualization with triangulation results
   - Explain confidence indicators and accuracy

5. **Exporting Data**
   - Demonstrate saving triangulation results
   - Show how to export audio samples or spectrograms

6. **User Interface Features**
   - Show annotation and marker functionality
   - Demonstrate frequency selection and filtering
   - Display real-time updates and alerts

## Recording Tips

1. **Keep it concise** - Aim for a 5-10 minute demonstration
2. **Use a good microphone** - Ensure clear audio narration
3. **Prepare the environment** - Close unnecessary applications
4. **Record in high resolution** - At least 1080p is recommended
5. **Add captions/annotations** - Consider adding text explanations during editing

## Post-Recording Steps

1. **Basic editing** - Trim unnecessary parts
2. **Add introduction** - Brief title and project overview
3. **Add captions** - For clarity and accessibility
4. **Export in appropriate format** - MP4 with H.264 encoding is widely compatible
5. **Upload to project repository** - Link the video in the README.md

## Suggested Video Outline

1. **Introduction** (30 seconds)
   - Brief overview of the SDR Triangulation Application
   - Purpose and main features

2. **Setup and Configuration** (1 minute)
   - Starting the application
   - Connecting to receivers

3. **Core Functionality Demo** (3-5 minutes)
   - Signal detection
   - Triangulation
   - Map visualization

4. **Advanced Features** (2-3 minutes)
   - Data export
   - Annotations
   - Configuration options

5. **Conclusion** (30 seconds)
   - Summary of capabilities
   - Call to action for trying the application
